# Pica Booth 项目进度

更新日期：2026-08-08

## 同步状态

- 远程仓库：`https://github.com/xhn000406/pica.git`（分支 `main`）
- 当前功能基线：多布局连拍（A/B/C/D/经典）+ 居中首页 + 滚动流程 + 本地导出 PNG

## 已完成

- 已将原本可点击的 01–04 标签流程改为同页纵向滚动流程；顶部轨迹仅显示当前阶段。
- 首页为居中文案 + 宠物照片条预览（简化后的 text-over-strip 构图）。
- 拍满当前布局所需张数后，“继续编辑”会平滑定位到编辑阶段；编辑完成后继续定位到导出阶段。
- 已接入浏览器真实摄像头权限与连拍，覆盖手机、macOS、Windows 浏览器。
- 拍摄取景与成片格统一按所选布局画幅裁切；拍摄前可看到最终进入相纸的区域。
- 拍摄页可选择多种拍立得布局（A/B/C/D/经典），张数与成片排列一致：
  - A：竖条 4 张
  - B：竖条 3 张
  - C：横图竖排 2 张
  - D：2×2 宫格 4 张
  - 经典：竖条 4 张（更接近传统 photo booth 画幅）
- 拍摄页右侧“会话照片条”、编辑弹窗、导出页统一按所选布局渲染。
- 编辑只保留滤镜与相纸颜色；默认白色相纸、无底板、无边框。
- 导出页可生成完整 PNG；触屏设备优先使用系统分享，桌面端下载 PNG。
- 导出 PNG 只包含照片条实体，不包含页面外层背景。

## 当前设计约定

- 用户通过滚动自然浏览阶段，或通过每阶段唯一的主按钮前进；不需要在顶部反复点流程标签。
- 开始拍摄后布局锁定；重新开始可切换布局。
- 照片在相纸格内铺满；相机取景和截图已同步裁切，避免拍摄后才出现意外裁切。
- 会话照片条默认使用白色相纸，以匹配编辑页默认效果。

## 建议下一步

1. 在手机、macOS、Windows 各实际完成一次：选布局 → 摄像头授权 → 连拍 → PNG 下载/分享回归测试。
2. 根据真机效果微调各布局取景框的构图位置与大小。
3. 如果要上线，使用 HTTPS 部署；手机浏览器需要安全上下文才能请求摄像头。

## 跨电脑协作

每次切换设备前执行：

```bash
git add .
git commit -m "描述本次改动"
git push origin main
```

另一台电脑开始前执行：

```bash
git pull origin main
npm install
npm run dev
```
