# Pica Booth 项目进度

更新日期：2026-08-02

## 已完成

- 已接入浏览器真实摄像头权限与四连拍，覆盖手机、macOS、Windows 浏览器。
- 拍摄取景与最终四连拍统一为竖向 `4:4.65` 画幅；拍摄前可看到最终进入相纸的区域。
- 拍摄页右侧“会话照片条”、编辑弹窗、导出页统一为同一套拍立得样式。
- 编辑只保留滤镜与相纸颜色；默认白色相纸、无底板、无边框。
- 导出页可生成完整 PNG；触屏设备优先使用系统分享，桌面端下载 PNG。
- 导出 PNG 只包含照片条实体，不包含页面外层背景。

## 当前设计约定

- 四张照片之间保留间距。
- 照片在相纸格内铺满；相机取景和截图已同步裁切，避免拍摄后才出现意外裁切。
- 会话照片条默认使用白色相纸，以匹配编辑页默认效果。

## 建议下一步

1. 在手机、macOS、Windows 各实际完成一次摄像头授权、四连拍、PNG 下载/分享回归测试。
2. 根据真机效果微调竖向取景框的构图位置与大小。
3. 如果要上线，使用 HTTPS 部署；手机浏览器需要安全上下文才能请求摄像头。

## 跨电脑协作

每次切换设备前执行：

```bash
git add .
git commit -m "描述本次改动"
git push origin main
```

另一台电脑开始前执行：

```bash
git pull origin main
npm install
npm run dev
```
